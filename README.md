This project applies machine learning to the Bank Marketing Dataset to predict whether a client will subscribe to a term deposit based on customer demographic, financial, and previous campaign interaction data.


Project Overview


The coursework explores the use of Random Forest Classification as a predictive AI model for banking marketing optimisation. The dataset was selected because it contains real-world banking campaign data from a Portuguese banking institution, making it suitable for analysing customer subscription behaviour.

The objective is to build a model that helps banks:

•	Identify high-probability customers
•	Improve marketing efficiency
•	Reduce customer acquisition costs
•	Increase campaign return on investment



Dataset


•	Dataset: Bank Marketing Dataset
•	Source: UCI Machine Learning Repository
•	Target Variable: Whether the client subscribes to a term deposit (Yes/No)
